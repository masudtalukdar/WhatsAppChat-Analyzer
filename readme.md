# 📱 WhatsApp Chat Analyzer

### *Unveil the hidden stories in your conversations.*

**WhatsApp Chat Analyzer** is a high-performance web application that transforms raw `.txt` chat exports into beautiful, interactive data visualizations. Built with privacy in mind, all processing happens locally in your browser—your personal data never touches a server.

---

## 🚀 Key Features

* **Deep Statistical Analysis:** Total messages, word counts, and average response times.
* **Behavioral Personas:** Identifies who is the "Night Owl," the "Emoji Master," or the "Essay Writer."
* **Sentiment Tracking:** Uses natural language processing to graph the emotional "vibe" of your chat over time.
* **Activity Heatmaps:** Visualizes which hours of the day and days of the week are your busiest.
* **Professional PDF Export:** Generate a multi-page, branded report with smart-slicing logic to prevent chart distortion.

---

## 📊 Intuitive Visualizations

The app provides a comprehensive dashboard that turns dry text into actionable insights:

* **Message Density:** See exactly when your relationship peaked or when the group chat went quiet.
* **Word Clouds:** Discover the most frequently used words and unique catchphrases.
* **Interaction Matrix:** A grid showing how participants respond to one another.

---

## 🛠️ Technology Stack

This project leverages modern web technologies to ensure speed and responsiveness:

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Charts:** [Chart.js](https://www.chartjs.org/) for high-performance, interactive data rendering.
* **PDF Generation:** [jsPDF](https://github.com/parallax/jsPDF) and [html2canvas](https://html2canvas.hertzen.com/) for high-resolution report exports.
* **Deployment:** Vercel

---

## 🔒 Privacy & Security

**Your privacy is our priority.** Unlike other analyzers, this app:

1. Does **not** upload your files to any server.
2. Processes all regex parsing and chart rendering **locally** on your machine.
3. Clears all data from memory as soon as you refresh the page.

---

## 📖 How to Use

1. Open **WhatsApp** on your phone.
2. Go to the chat you want to analyze -> **Settings** -> **Export Chat** -> **Without Media**.
3. Upload the test_data `.txt` file to the [Live Website(https://img.shields.io/badge/Demo-Live%20Now-brightgreen?style=flat-square)(https://whatsappchatstory.vercel.app/)

4. [![Live Demo](https://img.shields.io/badge/Demo-Live%20Now-brightgreen?style=flat-square)](https://your-link-here.com)
5. Explore your insights and download your PDF report!
